# DCRBN (`dcrbn.io`)

Public marketing site for **DCRBN**, a Las Vegas venture studio. The studio’s line is **Speed to Scale** for infrastructure companies in AI, blockchain, and quantum.

This repo is a Next.js App Router site. As of 18 Sep 2026, live `https://www.dcrbn.io/` still served an Express body of `OK!` behind Cloudflare. Apex `https://dcrbn.io/` 301s to www. Shipping this codebase is necessary but **not sufficient** until DNS / proxy for `www` points at this Vercel project.

## Local

```bash
npm install
npm run dev
```

Dev server defaults to [http://localhost:3010](http://localhost:3010).

```bash
npm run build
npm start
```

No secrets are required to build or browse the public pages.

## SEO

- `app/robots.ts` allows all crawlers on `/` and publishes the sitemap URL.
- `app/sitemap.ts` lists the public routes above.
- Each public page has title, meta description, canonical, Open Graph, and Twitter tags.
- Root layout ships Organization + WebSite JSON-LD. There is no sitewide `noindex` and no `X-Robots-Tag` header.
- Favicon / Apple icon and OG / Twitter images are generated by Next (`/icon`, `/apple-icon`, `/opengraph-image`).

After deploy, confirm:

- `https://www.dcrbn.io/robots.txt` allows `/` and includes `Sitemap: https://www.dcrbn.io/sitemap.xml`
- `https://www.dcrbn.io/sitemap.xml` lists the public URLs
- View-source on `/`, `/about`, and `/contact` shows a real HTML document with `<title>`, meta description, canonical, viewport, H1, OG/Twitter tags, and JSON-LD

## Optional Google Ads

If you have a real Google Ads tag, set these on the Vercel project (Production and Preview as needed):

- `NEXT_PUBLIC_GOOGLE_ADS_ID` — e.g. `AW-xxxxxxxxxx`
- `NEXT_PUBLIC_GOOGLE_ADS_CONVERSION_LABEL` — conversion label only

The gtag snippet loads **only** when `NEXT_PUBLIC_GOOGLE_ADS_ID` is set. The conversion event fires **only** after a successful `/apply` submit, and only when both variables are set. Do not commit placeholder IDs.

## Deploy to Vercel and attach `dcrbn.io`

The live problem is hosting, not missing pages in this repo. Apex already resolves to Vercel and 301s to www; www has been proxied to a Cloudflare / Express stub.

1. Import this GitHub repo (`bret1976/dcrbn-io`) into Vercel. Framework preset: Next.js. Build command: `npm run build`. Output: default Next.js (do not set a static `OK!` Express app as the production target).
2. In the Vercel project, open **Settings → Domains** and add both:
   - `dcrbn.io`
   - `www.dcrbn.io`
3. Prefer `www.dcrbn.io` as the canonical host (this site’s metadata already uses `https://www.dcrbn.io`). Keep apex as a 301 to www.
4. Point **www DNS** at Vercel, not the Express stub:
   - If using Vercel nameservers / Vercel A/CNAME records: `www` should CNAME to `cname.vercel-dns.com` (or the target Vercel shows).
   - If Cloudflare stays in front, set the `www` record to the Vercel target and use **DNS only** (grey cloud) **or** proxy to the Vercel deployment — not to the Express `OK!` origin. The Vercel project historically associated with this domain was named `ian-group-video-intro`.
5. Confirm a production deploy of **this** Next.js app is the domain’s current deployment (not an old serverless stub).
6. In Cloudflare (if still proxying):
   - Relax **Bot Fight Mode** / Super Bot Fight so verified **Googlebot** is not 403’d. The Sep 2026 audit saw full Googlebot UA requests return Cloudflare 403.
   - Do not add `X-Robots-Tag: noindex, nofollow, noarchive` on HTML or `robots.txt`.
   - Do not serve a `robots.txt` that `Disallow: /`.
7. After DNS settles, verify with curl:

   ```bash
   curl -sI https://www.dcrbn.io/
   curl -s https://www.dcrbn.io/ | head
   curl -s https://www.dcrbn.io/robots.txt
   curl -s https://www.dcrbn.io/sitemap.xml
   ```

   Homepage HTML should be the Next.js document, not `OK!`.
8. In Google Search Console, add `https://www.dcrbn.io/`, inspect `/`, and request indexing once robots allow crawl and Googlebot can fetch without 403.

## Forms

`/apply` posts to `/api/apply`. Delivery is optional: set `APPLY_WEBHOOK_URL` and/or `FORM_NOTIFY_EMAIL` in Vercel if you want submissions forwarded. The site still builds without them.
